## Understand the pieces

**Web** is the interface for your helpdesk. **API** handles helpdesk data, permissions and background work. **CLI and MCP** provide other ways to use the platform. Connect **NetRatel** to run configured automation, or **Netclaw** to bring an assistant into the workflow.

[See the architecture](/docs/reference/architecture/) · [Choose a deployment](/docs/deployment/overview/) · [Understand the security model](/docs/reference/security/)
